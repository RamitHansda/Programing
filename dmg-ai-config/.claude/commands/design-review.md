# /design-review

Review the provided design doc as an EM on a Zero Touch critical path.

Structure the response as:

1. Problem & success metric (gaps)
2. Invariants — which are testable?
3. Consistency / concurrency questions
4. Operability (flag, rollback, dashboards)
5. Decision: approve / approve-with-conditions / request-revision
6. Conditions or revision asks (max 5, ranked)

Be specific to the doc. Do not invent requirements not implied by the text; ask instead.
